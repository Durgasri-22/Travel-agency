# Sri Guru Tours and Travels 🌟

A modern, luxury, and high-converting travel agency website built for **Sri Guru Tours and Travels**.

## 🚀 Features

- **Cinematic Hero Section**: Full-screen banner with dark gradient scrim and client vehicle photography.
- **Quick Booking Estimator**: Generates instant custom itinerary quotes directly connected to WhatsApp.
- **Fleet Showcase**: Highlights client vehicles (Force Traveller, Passenger Car / SUV, SML Bus, Tourist Coach) with interactive details modals.
- **Tour Destinations**: Interactive destination circuits across South India (Ooty, Kodaikanal, Munnar, Coorg, Kerala, Tirupati, Mahabalipuram).
- **Why Choose Us**: Factual, trustworthy service pillars.
- **Responsive Photo Gallery**: Masonry grid with full-screen Lightbox (keyboard navigation + zoom).
- **Direct WhatsApp & Phone Integration**: Instant communication via `+91 90035 74884`.
- **Mobile Optimized**: Responsive layout with a sticky Call & WhatsApp action bar.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Durgasri-22/Travel-agency.git
cd Travel-agency
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
